# SOC-A5 Windows Memory Capture Source

This optional source lets a candidate reproduce the sealed incident inside a
real isolated Windows VM and acquire a memory image while the synthetic process
chain is resident. The shared case pack is sufficient for the scored mission;
this build is an additional pressure task. A locally captured image must not be
replaced with generated bytes or an empty container file.

Requirements:

- disposable Windows 11 evaluation VM with no real user data;
- an approved WinPmem binary obtained from its official release source;
- at least 16 GB free evidence storage;
- the candidate-specific synthetic archive and evidence marker;
- host-only networking to a candidate-controlled evidence collector.

Run `Invoke-SyntheticIncident.ps1`, then immediately run
`Capture-Memory.ps1`. Move the image and manifest to candidate-controlled
evidence storage before resetting the VM.
