Hands-On Projects — with full setup

Fifteen real builds across three tracks. Each project tells the intern exactly what to download and how, hands them a hard objective with a definite proof, and scales relentlessly. Revised after an external technical review: GRC rebuilt around a real ISO 27001 audit, EH-1 hardened against copying, tooling reliability fixed, and a proper verification + video-defense layer added.

Everything is download-and-run. Each project has a Set it up block with real commands. All targets are free and open-source. Nothing runs on netforge — interns build on their own machine, VM, or free-tier cloud, and submit the report + proof.
Verification & anti-bluff (applies to every project). Screenshots alone don't count — interns submit raw artifacts: command history, raw tool exports, file hashes, git commit history with timestamps. Each intern gets a unique variant (different target config / data / seed) so answers can't be shared. Projects 4 and 5 in every track require a video defense — a screen-recorded walkthrough where they reproduce a key step live and answer unseen questions ("show me the log line", "why not this alternative?", "what would change your conclusion?"). This is what an LLM-written report cannot survive.
Learn first, not walkthroughs. The hardest projects list a Learn first pointer to the technique (reading + a warm-up), never a walkthrough. Interns may learn the method — they must still do the work on their own variant. This keeps the bar high without cutting good raw talent that simply hadn't met the tool yet.
Ethical Hacking safety: every target is published specifically to be attacked (VulnHub, CloudGoat, GOAD…). Run on an isolated host-only network, self-owned targets only. Out-of-scope = automatic fail.
