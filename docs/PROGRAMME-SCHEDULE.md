# Operation Root Access — Programme Schedule

**Ubuntu Bridge Initiative · TRAN Foundation Programme**

A five-week run through Stages 0–4. One stage per week, a town hall every
Saturday, results the day after each submission. Add it to your calendar with
the file in *Add this to your calendar* below.

*All times are West Africa Time (WAT, UTC+1).*

## How every week works

1. **Monday — stage opens.** The new room unlocks. Read the briefing, meet the
   cast, walk the mission board.
2. **Monday to Sunday — do the work.** Clear the mission-board tasks and build
   your capstone folder.
3. **Saturday — town hall.** A live growth session (see below). Optional, but
   the interns who show up are the interns who grow fastest.
4. **Sunday 23:59 — submission deadline.** Your report folder link must be in
   before the clock runs out. Late submissions are graded as late.
5. **Monday — results.** One day after submission, marketing announces the
   stage is complete and results are released. The next stage opens the same
   day.

## The rules that matter

- **Sunday 23:59 WAT is the hard deadline** for each stage. Submit early; do
  not race the clock.
- **You advance stage by stage.** Stage *N+1* opens to you once Stage *N* is
  passed.
- **Town halls are every Saturday.** Block the time now.
- **Results come one day after you submit** — every Monday.

## Add this to your calendar

Import **`operation-root-access.ics`** (in this same folder) into Google
Calendar, Outlook, or Apple Calendar. It contains every stage window, every
submission deadline, every results day, and all five Saturday town halls.

- **Google Calendar:** Settings → Import & export → Import → choose the file.
- **Apple Calendar:** File → Import → choose the file.
- **Outlook:** File → Open & Export → Import an iCalendar (.ics) file.
