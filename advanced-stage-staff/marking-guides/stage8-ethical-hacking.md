# Stage 8 Ethical Hacking Marking Guide: Portable Directory Control Plane

Score only the issued offline B2 range and candidate-bound assignment, or a compatibility export that satisfies the identical graph and test contract. GOAD is optional and earns no hardware credit. Never reward testing of a real or shared directory.

## Rubric (100)

| Area | Points | Full-credit standard |
|---|---:|---|
| Release integrity and scope | 10 | Correct archive and candidate binding; clean-state manifest; health passes; work remains inside the issued offline range. |
| Ingestion and effective-rights model | 20 | Versioned schema; users, groups, computers, SPNs, sessions, membership, ACLs, delegation, and state parsed; at least eight accepted edges have direct source evidence; planted stale edge rejected for the correct failed precondition. |
| Path discovery and validation | 25 | Two independent proof paths discovered from data; every edge has raw locator and effective-rights reasoning; at least one path combines credential abuse with ACL or delegation; proof limits observed. |
| Automation and cleanup | 20 | One candidate-authored path resolves dynamic identifiers, succeeds 3/3 from clean state, fails safely, and leaves machine-verifiable zero temporary state. |
| Detection and remediation | 15 | Two event-sequence detections pass positive and benign controls; both root causes remediated; intended path tests fail while health, legitimate access, and unrelated assertions stay green. |
| Recorded defense | 10 | Candidate rebuilds clean state and reproduces a staff-selected edge using submitted code, then explains evidence and cleanup. |

## Scoring rules

- Graph visualization without raw edge validation earns no direct-validation points.
- Hard-coded object names, IDs, paths, proof values, markers, or expected answers receive no automation credit for the affected behavior.
- Proof retrieval beyond the two assigned objects, persistence, or use of a real directory is a safety failure and must be escalated.
- A remediation that merely hides the proof or breaks legitimate access does not earn remediation credit.
- Do not impose an undisclosed cap. Score each demonstrated criterion and explain every deduction.

## Required feedback

List the exact files and commands assessed, each accepted and rejected edge, both paths, 3/3 outcomes, cleanup residuals, detection verdicts, remediation retests, arithmetic, and prioritized improvements. Record boundary-tie rereads explicitly.
