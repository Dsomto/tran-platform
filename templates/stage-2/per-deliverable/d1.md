## Page 5 — The three conclusions

This page answers three questions the grader checks by name. Get all three right and D1 sits in the top band.

### (a) The exposed service that gave first **live** data — with timestamp proof

[Name the service explicitly: **Elasticsearch**, not Redis. State your proof as the inequality `03:06:44 > 03:06:12` and say in one sentence what each timestamp is (the first live query vs. the moment the scan was cut off). Then name the decoy directly and say why you rejected it.

**Required decoy rejection — write this:** "The Task 1 README points at the Redis cache as the first data source. I reject it: [your reason — the scan that touched Redis was cut off at 03:06:12, and the first live customer-data query did not land until 03:06:44, so the live data could not have come from the cut-off scan]." Citing Redis as load-bearing costs you here **and** again in D3.]

### (b) The attacker IP, justified by behaviour

[Name the IP. Then justify it by **behaviour, not order of appearance**. The first IP to touch `/legacy-admin` is not necessarily the attacker. The attacker is identified by (1) a user-agent that is a *tool* — `python-requests`, not a browser string — and (2) the fact that it actually **retrieved `.env`**. State both. 

*Example shape: "Several IPs probe `/legacy-admin`. I attribute the intrusion to [IP] on two behavioural grounds: its user-agent is `python-requests/…` — automation, not Firefox — and it is the only source that successfully retrieved `.env` (cite the line). Touching a path and retrieving it are different; attribution follows the retrieval."*]

### (c) The one retrieved path that changed the outcome — vs. the interesting-but-not-load-bearing one

[Name the **load-bearing** retrieval (the one whose contents changed what the attacker could do next — e.g. the `.env` retrieval that handed over the secret that unlocked the rest of the chain). Then name one path that is **interesting but not load-bearing** (e.g. an enumeration that revealed structure but no secret) and say why it is the lesser of the two.
